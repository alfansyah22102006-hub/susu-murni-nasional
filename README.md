# Susu Murni Nasional — Prototype Pastel

Versi ini lebih dekat dengan struktur prototype awal:
1. Hero dengan nuansa gunung/ladang/sapi
2. Value proposition
3. Best seller
4. Sejarah / cerita brand
5. CTA “Yuk, coba segar hari ini!”
6. Halaman Produk
7. Halaman About Us
8. Halaman Contact + peta lokasi + ruang konten promosi

Palet dibuat pastel: sage green, cream, blush pink, butter yellow, dan soft blue.

- Susu Cup Pasteurisasi: Rp5.000 → Rp3.000

Alamat: Jl. Raya Kopeng Km 5, Desa Sumogawe, Kecamatan Getasan, Kabupaten Semarang, Jawa Tengah.
